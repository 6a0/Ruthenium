# Branding

Ruthenium's own artwork. The only place the content check allows images.

- `ruthenium.png`: the logo mark, 1920×1920 with transparency. The client embeds it
  (title screen, window icon), downscaled at start-up.
- `ruthenium.svg`: the same mark as SVG (it wraps an embedded raster, so it is no sharper
  than the PNG).
