# Security policy

Ruthenium handles Microsoft and Minecraft account tokens. Please report vulnerabilities privately:

- through GitHub's "Report a vulnerability" (private security advisory) on this repository, or
- by email to [sixazero@outlook.com](mailto:sixazero@outlook.com).

Please don't open public issues for security problems. Expect an acknowledgement within 7 days.

Only the latest release, and the `main` branch before the first release, receive fixes.
